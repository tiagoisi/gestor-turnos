# User Stories

### El usuario invitado debe poder: 
1. Registrarse 
2. Crear una cuenta nueva 
3. Al momento de crear una cuenta deberá llenar un formulario 

### El usuario registrado debe poder:
1. Iniciar sesión con sus credenciales 
2. Si las credenciales son incorrectas el usuario no deberá poder iniciar sesión 
3. Reservar un turno 
4. Cerrar sesión 
5. Cancelar un turno *(hasta un dia antes del mismo)*
6. Visualizar en una sección todas sus reservas y el estado de cada una de ellas 
7. *(EXTRA CREDIT)* Recibir un mail de confirmación luego de reservar o cancelar un turno 
8. *(EXTRA CREDIT)* Subir una foto de perfil a la plataforma a través de un archivo de imagen
